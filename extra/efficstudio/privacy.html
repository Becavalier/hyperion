EfficStudio 隐私政策 · Privacy Policy

最后更新 Last updated: 2026-10-29

适用范围 Scope

EfficStudio 是 EfficLab中文 频道主自用、只在本人电脑上运行的工具，没有其他用户。本政策说明它如何处理频道主授权给它的 Google 账号数据。

EfficStudio is a personal tool used only by the owner of the EfficLab中文 channel and runs only on the owner's own computer; it has no other users. This policy describes how it handles the Google account data the owner authorizes it to use.

使用的 Google 数据 Google data used

  • 只申请 https://www.googleapis.com/auth/youtube.upload 一项权限：上传频道主自己的视频、设置视频缩略图。
    It requests one scope only, youtube.upload: uploading the owner's own videos to the owner's own channel and setting their thumbnails.
  • 不读取、不修改、不删除账号里的任何其他内容（其他视频、评论、订阅、个人资料等）。
    It does not read, change or delete anything else in the account (other videos, comments, subscriptions, profile).

存储 Storage

授权令牌只保存在频道主本人电脑的本地文件中（仅本人可读的权限），不上传到任何服务器，也不进入任何代码仓库。

The OAuth token is stored only in a local file on the owner's computer, readable by the owner alone. It is never sent to any server other than Google's, and never committed to any code repository.

共享 Sharing

不收集、不出售、不与任何第三方分享任何数据。上传的视频及其标题、简介、标签、封面只发送给 YouTube（Google）。

No data is collected, sold or shared with any third party. Uploaded videos and their titles, descriptions, tags and thumbnails are sent to YouTube (Google) only.

Google API 服务用户数据政策 Google API Services User Data Policy

EfficStudio 对从 Google API 获得的信息的使用，遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

EfficStudio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

撤销授权 Revoking access

频道主可随时在 Google 账号的第三方应用权限 页面撤销授权，并删除本地令牌文件。

The owner can revoke access at any time on the Google Account third-party access page and delete the local token file.
